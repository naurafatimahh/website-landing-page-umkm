# Brand Lumaa

Landing page sederhana untuk memperkenalkan brand Lumaa dan koleksi pashmina. Halaman menampilkan hero, pengenalan brand, daftar produk, harga, serta tautan kontak dan media sosial.

## Menjalankan Website

Tidak perlu instalasi atau build. Buka `index.html` langsung di browser, atau jalankan folder ini menggunakan ekstensi Live Server di Visual Studio Code.

Koneksi internet dibutuhkan untuk memuat font Google Fonts dan foto dari Unsplash.

## Struktur Folder

```text
.
├── index.html
├── css/
│   └── style.css
├── assets/
│   └── images/
└── docs/
    ├── requirements.md
    └── testing.md
```

## Teknologi

- HTML5
- CSS3
- Google Fonts: Cormorant Garamond dan DM Sans

## Kustomisasi

- Ubah konten halaman, nama produk, harga, serta tautan di `index.html`.
- Sesuaikan warna, tipografi, dan tata letak di `css/style.css`.
- Ganti logo di `assets/images/lumaa-logo.png`.
- Sebelum dipublikasikan, ganti alamat email, nomor WhatsApp, dan akun media sosial dengan informasi resmi Lumaa. Foto Unsplash juga dapat diganti dengan foto produk Lumaa.

Dokumentasi kebutuhan website tersedia di [`docs/requirements.md`](docs/requirements.md).
